# 08 Arrays

## Learning objectives
Understand the topic, trace code by hand, and write independent Java programs.

## Key ideas
Read each example, identify inputs and outputs, and explain the control flow.

## Worked examples
- `examples/ArraySum.java`
- `examples/LargestElement.java`
- `examples/ArrayAverage.java`
- `examples/MatrixAddition.java`

## How to run
```bash
javac examples/ArraySum.java
java -cp examples ArraySum
```
