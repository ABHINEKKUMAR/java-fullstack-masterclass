# ICSE Class 9 Java

This learning track supplements classroom teaching. Check the official syllabus for your examination year.

## Learning sequence
1. Java fundamentals and execution
2. Primitive data types and casting
3. Arithmetic, relational, logical operators
4. Scanner input and formatted output
5. if, else, switch
6. for, while, do-while
7. Nested loops
8. Patterns and dry runs
9. Math library
