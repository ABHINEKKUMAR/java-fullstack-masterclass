# 01 Introduction to Java

## Learning objectives
Understand the topic, trace code by hand, and write independent Java programs.

## Key ideas
Read each example, identify inputs and outputs, and explain the control flow.

## Worked examples
- `examples/HelloWorld.java`
- `examples/PrintDetails.java`

## How to run
```bash
javac examples/HelloWorld.java
java -cp examples HelloWorld
```

## Practice
See `exercises.md`. Write your own solution before comparing with examples.
