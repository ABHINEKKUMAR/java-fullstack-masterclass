# 05 Conditional Statements

## Learning objectives
Understand the topic, trace code by hand, and write independent Java programs.

## Key ideas
Read each example, identify inputs and outputs, and explain the control flow.

## Worked examples
- `examples/EvenOdd.java`
- `examples/LargestOfThree.java`
- `examples/LeapYear.java`
- `examples/GradeCalculator.java`
- `examples/SwitchCalculator.java`

## How to run
```bash
javac examples/EvenOdd.java
java -cp examples EvenOdd
```
