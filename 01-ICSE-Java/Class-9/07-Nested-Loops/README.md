# 07 Nested Loops

## Learning objectives
Understand the topic, trace code by hand, and write independent Java programs.

## Key ideas
Read each example, identify inputs and outputs, and explain the control flow.

## Worked examples
- `examples/StarTriangle.java`
- `examples/NumberTriangle.java`
- `examples/StarPyramid.java`

## How to run
```bash
javac examples/StarTriangle.java
java -cp examples StarTriangle
```
