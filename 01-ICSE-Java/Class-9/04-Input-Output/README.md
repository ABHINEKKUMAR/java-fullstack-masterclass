# 04 Input Output

## Learning objectives
Understand the topic, trace code by hand, and write independent Java programs.

## Key ideas
Read each example, identify inputs and outputs, and explain the control flow.

## Worked examples

## How to run

```bash
javac examples/ScannerInput.java
java -cp examples ScannerInput
```
